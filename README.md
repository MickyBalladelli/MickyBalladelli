A portfolio of the projects I have been building across AI, local tooling, macOS apps, web experiences, visualization, and developer frameworks.

This README reflects the public repositories currently visible on my GitHub profile and summarizes the work in each project.

## Profile

- GitHub: https://github.com/MickyBalladelli
- Focus: AI tooling, local-first apps, data visualization, macOS utilities, UI libraries, and experiments in JavaScript, Rust, Swift, and PowerShell

## Project portfolio

### AI and local model tooling

- [ask-ollama](https://github.com/MickyBalladelli/ask-ollama) — Local chat app for Ollama with a React + Material UI interface and Electron desktop shell.
- [Ghost](https://github.com/MickyBalladelli/Ghost) — Local-first AI assistant and agent tooling for Ollama, MLX/VLM, OpenAI-compatible servers, and headless OpenCode setups.
- [OxideLM](https://github.com/MickyBalladelli/OxideLM) — Bare-metal pure-Rust transformer engine with custom reverse-mode autograd, BPE tokenization, and wgpu acceleration.
- [qwythos](https://github.com/MickyBalladelli/qwythos) — Custom model based on the uncensored Qwythos-9B-Abliterated base model and optimized via Ollama.
- [bonsai](https://github.com/MickyBalladelli/bonsai) — Repository compression tool for compact, token-efficient XML/JSON context packaging used with LLMs and agent workflows.
- [ImageGen](https://github.com/MickyBalladelli/ImageGen) — Image-generation or creative media experiment.
- [auraroute](https://github.com/MickyBalladelli/auraroute) — Work-in-progress routing or platform project.
  
### macOS utilities and desktop tools

- [authenticator](https://github.com/MickyBalladelli/authenticator) — Lightweight native macOS menu-bar 2FA/TOTP authenticator built with SwiftUI, CryptoKit, and Keychain Services.
- [sysmon](https://github.com/MickyBalladelli/sysmon) — Sandbox-compliant macOS application for real-time CPU and memory monitoring.
- [MacTemp](https://github.com/MickyBalladelli/MacTemp) — macOS-focused temperature/monitoring utility.
- [AltTab](https://github.com/MickyBalladelli/AltTab) — Desktop workspace utility project.

- [virusglobe](https://github.com/MickyBalladelli/virusglobe) — Coronavirus data visualization built with React and Globe.js.

- [spectra](https://github.com/MickyBalladelli/spectra) — Search console for messy document collections, helping teams turn unstructured files into searchable knowledge.
